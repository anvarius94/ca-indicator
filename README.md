# ca-indicator
Расширение для Chrome, которое показывает, **кто на самом деле подписал сертификат сайта**: публичный удостоверяющий центр — или корень, установленный на вашем компьютере.  Ничего не блокирует и никуда не лезет: всеми сайтами вы пользуетесь как раньше, просто видите, чем именно защищён каждый из них.
